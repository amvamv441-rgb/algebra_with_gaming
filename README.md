## 📖 درباره پروژه

این پروژه یک **بازی آموزشی تعاملی** برای یادگیری **فصل اول کتاب حسابان ۱ (پایه یازدهم، رشته ریاضی و فیزیک)** است. هدف این پروژه، تبدیل یادگیری خشک و کسل‌کننده ریاضی به تجربه‌ای جذاب، بصری و تعاملی است.

تمام محتوای آموزشی بر اساس **کتاب درسی رسمی** تهیه شده و شامل درس‌نامه، مثال‌های حل‌شده، انیمیشن‌های مفهومی و آزمون‌های تعاملی است. دانش‌آموز می‌تواند بدون نیاز به نصب هیچ نرم‌افزاری، فقط با باز کردن یک فایل HTML در مرورگر، تمام فصل اول را یاد بگیرد و خود را محک بزند.

> **فلسفه پروژه:** یادگیری ریاضی وقتی جذاب می‌شود که دانش‌آموز بتواند مفاهیم را *ببیند*، *بشنود* و *لمس کند* — نه فقط بخواند.

## ✨ ویژگی‌های کلیدی

### 📚 محتوای آموزشی کامل
- **۵ درس کامل** از فصل اول حسابان ۱
- مطابق با **کتاب درسی رسمی** وزارت آموزش و پرورش
- مثال‌های حل‌شده از خود کتاب
- نکات کلیدی و فرمول‌های مهم

### 🎬 انیمیشن‌های مفهومی
- **انیمیشن نقطه‌ای** برای نمایش مجموع دنباله‌ها
- **رسم پارامتریک سهمی** و روابط ریشه‌ها
- **نمودار تعاملی** معادلات رادیکالی
- **شکل V** قدر مطلق با رسم مرحله‌به‌مرحله
- **نمایش بصری** فاصله دو نقطه و نقطه وسط

### 🎮 آزمون‌های تعاملی
- **۱۲ سؤال برای هر درس** (۶ سؤال تصادفی در هر بار)
- **۲۰ سؤال امتحان نهایی** از آزمون‌های ۱۴۰۳ و ۱۴۰۴
- **۳۰ سؤال کنکور** سراسری و آزمایشی
- گزینه‌های تصادفی (ضد حفظ‌کردن جواب)
- بازخورد فوری با راه‌حل کامل

### 🔊 سیستم صوتی
- افکت‌های صوتی برای پاسخ درست/غلط
- **موسیقی پس‌زمینه** آرام برای تمرکز
- تنظیم حجم صدا از **سه نقطه مختلف**

### 🎨 تم و ظاهر
- **حالت شب و روز** با ذخیره خودکار
- **تنظیم اندازه فونت** برای خوانایی بهتر
- **کاهش انیمیشن** برای افراد حساس
- طراحی **ریسپانسیو** برای موبایل و تبلت

### 🧭 ناوبری هوشمند
- **منوی سه‌نقطه** برای دسترسی سریع به تنظیمات
- **منوی فصل‌بندی‌شده** برای جابه‌جایی بین درس‌ها
- **ذخیره خودکار** آخرین صفحه بازدید‌شده
- **نوار پیشرفت** مطالعه در بالای صفحه

### 🎯 امکانات آموزشی
- **رندر ریاضی حرفه‌ای** با KaTeX
- **پشتیبانی کامل RTL** برای فارسی
- **جدول امتیازات** و پیام‌های تشویقی
- **کارت پایان فصل** با تبریک

## 🛠 تکنولوژی‌های استفاده‌شده

| تکنولوژی | کاربرد |
|----------|--------|
| **HTML5** | ساختار صفحات |
| **CSS3** | استایل، تم، انیمیشن |
| **JavaScript (Vanilla)** | منطق بازی، تعاملات |
| **KaTeX** | رندر فرمول‌های ریاضی |
| **Web Audio API** | تولید صداهای افکت و موسیقی (بدون فایل خارجی) |
| **Canvas API** | پس‌زمینه شناور نمادهای ریاضی |
| **IntersectionObserver** | انیمیشن‌های بر اساس اسکرول |
| **localStorage** | ذخیره تنظیمات کاربر |
| **SVG** | نمودارها و شکل‌های هندسی |
| **Vazirmatn Font** | فونت فارسی خوانا |

> **نکته:** این پروژه **بدون هیچ فریم‌ورک یا کتابخانه سنگین** ساخته شده و کاملاً **Self-Contained** است — فقط یک فایل HTML!
