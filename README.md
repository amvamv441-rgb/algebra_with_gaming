## 📖 درباره پروژه

«حسابان ۱ — آزمایشگاه فصل اول» پنج درس **فصل اول: جبر و معادله** را با یک رویکرد تازه آموزش می‌دهد: به‌جای حفظ کردن فرمول، آن را **ببین، بچرخان و با دست‌های خودت بساز**.

- درس‌نامه‌ی کامل با مثال‌های حل‌شده، خطاهای رایج و جمع‌بندی
- **شش آزمایشگاه سه‌بعدی** (Three.js) که با کشیدن، چرخاندن و اسلایدر زنده تغییر می‌کنند
- **۳۱۷ سؤال** با پاسخ تشریحی، به‌علاوه‌ی مولد سؤال بی‌پایان
- پیشرفت، XP، نشان‌ها، زنجیره‌ی روزانه و چالش روزانه — همه روی دستگاه خود کاربر ذخیره می‌شود
- کاملاً **آفلاین و بدون فریم‌ورک**؛ همه‌ی وابستگی‌ها (KaTeX، Three.js، فونت‌ها) داخل ریپو هستند

> **ساختار درس‌ها دقیقاً مطابق فهرست رسمی کتاب حسابان (۱)** (چاپ ۱۴۰۴–۱۴۰۵، فصل اول «جبر و معادله»):
> ۱. مجموع جملات دنباله‌های حسابی و هندسی · ۲. معادلات درجه دوم · ۳. معادلات گویا و گنگ · ۴. قدر مطلق و ویژگی‌های آن · ۵. آشنایی با هندسه تحلیلی

## ✨ چه چیزهایی در این نسخه هست

### 🧪 آزمایشگاه‌های سه‌بعدی
| صحنه | درس | چه کاری می‌کند |
|---|---|---|
| سهمی‌گون هولوگرام | صفحه‌ی اصلی | شبکه‌ی سهمی‌گون، ذرات و برچسب‌های شناور؛ با کشیدن می‌چرخد |
| میله‌های دنباله | درس ۱ | دنباله‌ی حسابی/هندسی را به‌صورت میله‌های سه‌بعدی با a، d، q و n قابل تغییر می‌سازد |
| سهمی و ریشه‌ها | درس ۲ | نمودار $ax^2+bx+c$، ریشه‌ها، رأس و دلتا را زنده نمایش می‌دهد |
| تقاطع رادیکالی | درس ۳ | $\sqrt{x+2}=x-4$ با خط اسکن متحرک؛ نقطه‌ی جواب خارجی مشخص است |
| تا کردن قدر مطلق | درس ۴ | نمودار $f(x)$ با یک انیمیشن «تا شدن» به $|f(x)|$ تبدیل می‌شود |
| هندسه‌ی تحلیلی | درس ۵ | پاره‌خط AB، نقطه‌ی میانی و فاصله در فضای سه‌بعدی |

### 📚 درس‌نامه
هر درس شامل چند بخش با بلوک‌های متن، فرمول، مثال حل‌شده، نکته/هشدار، جدول، گام‌به‌گام، اشتباه‌های رایج و **شکل‌های SVG انیمیشنی** (نمایش گاوس برای مجموع ۱ تا ۱۰، سه حالت دلتا، روابط ویت، محور اعداد، تا شدن قدر مطلق، دستگاه مختصات) است.

### 📝 بانک سؤال
| بانک | تعداد | توضیح |
|---|---:|---|
| درس ۱ تا ۵ | ۳۷ + ۴۰ + ۴۰ + ۳۶ + ۴۴ | آسان / متوسط / سخت، با پاسخ تشریحی |
| امتحان نهایی | ۵۰ | ترکیبی از کل فصل، سبک امتحان پایانی |
| سبک کنکور | ۷۰ | سؤال‌های ترکیبی و سخت‌تر |
| **جمعاً** | **۳۱۷** | |

اگر بانک یک درس تمام شود، **مولد سؤال** برای همان درس سؤال تازه (با جواب و راه‌حل دقیق) می‌سازد؛ بنابراین تمرین عملاً بی‌پایان است.

### 🎯 تمرین و آزمون
- **تمرین سفارشی:** انتخاب درس (یا مرور ترکیبی)، سطح و تعداد سؤال
- **حالت تمرین:** بازخورد فوری + راه‌حل کامل + امتیاز زنجیره
- **حالت آزمون:** تایمر، پالت سؤال‌ها، جابه‌جایی بین سؤال‌ها، بدون نمایش جواب تا پایان
- **تحلیل نتیجه:** درصد، امتیاز، نمودار رادار موضوعی و مرور کامل پاسخ‌ها
- **چالش روزانه:** ۶ سؤال از کل فصل با seed تاریخ روز (+۵۰ امتیاز)

### 🏆 پیشرفت و انگیزش
- ۹ سطح (از «تازه‌کار» تا «حسابان‌کار»)، ۱۴ نشان، زنجیره‌ی روزانه
- درصد تسلط هر درس بر اساس پاسخ‌های اخیر
- تاریخچه‌ی تمرین‌ها و امکان پاک‌کردن پیشرفت

### 🎨 ظاهر و دسترس‌پذیری
- دو تم «تخته‌سیاه» (تیره) و «دفتر» (روشن) + حالت سیستم
- سه اندازه‌ی متن، حالت کاهش حرکت، کلیدهای ۱ تا ۴ برای پاسخ، Ctrl+Enter در آزمون
- ریسپانسیو کامل (نوار پایین در موبایل)، رندر KaTeX، پشتیبانی چاپ
- همه‌ی افکت‌های صوتی با Web Audio تولید می‌شوند (بدون فایل صوتی)

### فرمت داده‌ها (برای توسعه‌دهندگان)

**درس:** `AWG.addLesson({ id, num, title, short, desc, lead, minutes, questions, color, tags, sections:[{ id, label, title, blocks:[...] }], keyPoints })`
بلوک‌ها: `p`, `formula`, `example`, `note`, `story`, `steps`, `list`, `table`, `mistakes`, `summary`, `visual`, `lab`.

**سؤال خام:** `{ q, a:[۴ رشته، گزینه‌ی درست در اندیس ۰], c:0, s, lv:1|2|3, tp }` و ثبت با `AWG.addBank('lesson1', B)`.
گزینه‌ها هنگام نمایش به‌صورت تصادفی مرتب می‌شوند؛ در متن‌ها از `$...$` برای ریاضی استفاده کنید و به‌جای `<` و `>` از `\lt` و `\gt`.

## 🚀 اجرا

هیچ build لازم نیست. کافی است ریپو را کلون کرده و یک سرور استاتیک ساده اجرا کنید (به‌خاطر فایل‌های محلی، باز کردن مستقیم `index.html` با `file://` در بعضی مرورگرها محدود است):

```bash
# Python
python3 -m http.server 8000
# یا Node
npx serve .
```

سپس <http://localhost:8000> را باز کنید.

برای انتشار در **GitHub Pages**: Settings → Pages → شاخه‌ی `main`، پوشه‌ی `/ (root)`.
